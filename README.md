# progetto-ID - TONALIA
Tonalia è una web app di interior design. Con un test interattivo di 3 step, aiutiamo le persone a trovare il proprio stile, mood e toni cromatici, proponendo una moodboard su misura con codici pittura NCS e materiali d’arredo, più la possibilità di richiedere render 3D.
