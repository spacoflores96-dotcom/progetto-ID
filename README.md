# progetto-ID - TONALIA
Tonalia è una web app di interior design. Con un test interattivo di 3 step, che genera codici univoci e palette di colori per 32 combinazioni di design basate su **Stile**, **Stato d'Animo** e **Palette Colori**.
Aiutiamo le persone a trovare il proprio stile, mood e toni cromatici, proponendo una moodboard su misura con codici pittura NCS e materiali d’arredo, più la possibilità di richiedere render 3D.

## Struttura del Codice
- `index.html`: Struttura del selettore a 3 livelli.
- `style.css`: Stili responsivi e griglia delle palette.
- `script.js`: Logica di generazione dei codici (`STILE-MOOD-PALETTE`) e calcolo automatico del contrasto testo.
